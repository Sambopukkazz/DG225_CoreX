# Imaginophobia — Art Direction

**Version:** 1.1 | **Last Updated:** 2026-10-24

## Visual Style

- **สไตล์:** 2D pixel art มุมมองด้านข้าง (side-view)
- **โทนรวม:** มืด หม่น ชื้นแฉะ อึดอัด — ใช้ความมืดเป็นองค์ประกอบหลัก ไม่ใช่แค่ฉากหลัง
- **แนวทางศัตรู:** สีดำขาวสไตล์ contrast จัด ให้ความรู้สึกเกินจริง (surreal) — เอาคำอธิบายของแต่ละความกลัวมาเป็นสิ่งที่มองเห็นได้

## Main Character Design

**สีหลัก : Navy Blue** (น้ำเงินเข้ม/น้ำเงินกรมท่า)

- บ่งบอกถึงลักษณะอาชีพ/เครื่องแบบช่างอย่างชัดเจน

**สีรอง : Brown & Beige** (น้ำตาล, น้ำตาลเทา และโทนสีเนื้อ)

- การใช้สีน้ำตาลตัดกับสีน้ำเงินให้ความรู้สึกติดดิน และช่วยเพิ่มน้ำหนักความสมจริงให้กับอุปกรณ์

**สิ่งที่ปรับจากเวอร์ชันเดิม**

| สิ่งที่ปรับ                 | เหตุผล                                                                                                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ดวงตาที่เปิดกว้าง     | สื่อถึงความตื่นตระหนก ความไม่ไว้วางใจ                                                                                                           |
| ท่าทางที่ห่อตัว         | เป็น "ท่าป้องกัน" ทางวิทยาศาสตร์ สื่อว่าตัวละครพยายามทำให้ตัวเองดูเล็กลงและระมัดระวังมากขึ้น |
| การหันหน้ากลับไปมอง | ใช้ในมุมมองด้านหลังและมุมมอง 3/4 (เฉียง) เป็นหลักของความหวาดระแวง                                                          |
| สีที่หม่นและมืดลง     | สีน้ำเงินเข้มของชุดและหมวกถูกปรับให้หม่นและมืดลง และสีผิวซีดลง                                                         |

## Environments

### โถงอุโมง (Sewer)

โทนสีเย็นและมืด (สีน้ำเงินเข้ม สีเทา และสีดำ) ร่วมกับรายละเอียดอย่าง **แอ่งน้ำขังบนพื้น** และ **คราบตะไคร่น้ำตามซอกอิฐ** ช่วยส่งเสริมบรรยากาศที่เย็นเยือก ชื้นแฉะ สร้างความรู้สึกหดหู่ใจ และความเหงา

### ห้องไฟฟ้า (Electrical Room)

นำ inspiration จากห้องไฟที่พบได้ทั่วไปในชั้นใต้ดินของตึกต่างๆ แต่ปนความสกปรกและ texture ของท่อน้ำไปด้วย

ห้องไฟเป็นห้องที่มีแสงมากกว่าที่อื่น ๆ แสงสลัวเพื่อให้รู้สึกอบอุ่น ปลอดภัย เหมือนเป็น **safe zone** — ซึ่งเปลี่ยน concept ไปจากช่วง Game Jam ที่ห้องไฟสามารถมี entity ได้

**องค์ประกอบในห้อง** (จาก wireframe): hanging light bulb (broken) · light switch (deco) · entrance to sewer · useless door · locker for hiding · deco

## Enemy / Phobia Design

แนวทาง: นำคำอธิบายของแต่ละความกลัวมาเป็นสิ่งที่มองเห็นได้ตามจินตนาการ แล้วนำ concept นั้นมาใช้เป็น mechanic ของ phobia

| Phobia                | การออกแบบ                                                                                                            | Mechanic ที่ผูกกัน                                                                                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Scopophobia** | เหมือนหนอนที่มีลูกตาหลายดวงคอยจับตามอง แล้วพุ่งผ่านด้วยความเร็ว | ความเร็วที่พุ่งผ่าน = ความกดดันที่ได้รับเวลาถูกจับตามอง → ต้องหาที่ซ่อนเพื่อหลบความรู้สึกนั้น |
| **Autophobia**  | เงาร่างดำทึบ                                                                                                      | "You aren't scared of being alone, you are scared of NOT being alone" · เงาเดินตามความเร็วมากกว่าผู้เล่น                                             |
| **Nyctophobia** | "The unknown" — ความมืดที่ขยายตัวกลืนกินจอ | เมื่อหมดเวลาหรืออยู่ในความมืดนาน จอจะถูกกลืน |
| **Entamaphobia** | ผีที่ยืนอยู่หลังตู้เสื้อผ้าที่ปิดอยู่ — สูงมาก ผอมผิดปกติ หน้าเบี้ยว มือและขาใหญ่ยาว ให้ความรู้สึกว่า "ใหญ่จนไม่น่าจะใส่ในที่แคบได้ แต่ก็ใส่ได้" · ตัวใหญ่กว่าผู้เล่นหลายเท่า | กลัวแสง (เข้าห้องที่มีแสงไม่ได้) · โผล่ทีละส่วนตาม stage ผ่านช่องใต้ประตู (ขา → มือกด → มือบีบ → หน้า) → ต้องแอบมองใต้ช่องประตู + ส่องไฟฉายเพื่อไล่กลับ |

## UI / UX

**Main Menu** — ภาพ first-person มองลงไปในทางเดินชั้นใต้ดินมืด ๆ มีมวลความมืดที่มีลูกตาเต็มไปหมดอยู่กลางจอ ข้อความ "Game Name" ทับอยู่ด้านบน และเมนูเรียงลงมา: `PLAY GAME` · `OPTIONS` · `EXIT`

**HUD** (มุมซ้ายบน)

```
Objective : Fix everything and leave
Sanity    : 100
Battery   : 100
```

**หน้าจอที่ต้องมี** — Main menu · Settings (Ambience Volume, SFX Volume) · Credits · Gameplay · Death · Win · Minigame screens (Connect The Dots, Spin The Valve, Door Peeking)

> ✅ **สถานะในโค้ด (2026-10-25):** หน้าจอทั้งหมดข้างบนมีแล้ว (สร้างด้วย Gum) — รายการปุ่มจริงบนเมนูคือ `Shift 1` (เริ่มเกม) · `Index` (ยังปิดใช้งาน) · `Settings` · `Credits` · `Exit` และมี pause overlay (เปิดด้วย `ESC`/ปุ่มมุมขวาบน) ระหว่างเล่น
> ⚠️ จอชนะยังมีบรรทัดเวลาเป็น placeholder (`"Time left: lorem ipsum"`) และจอแอบมองประตูยังเป็นสี่เหลี่ยมสีเขียว ต้องทำอาร์ตจริง
