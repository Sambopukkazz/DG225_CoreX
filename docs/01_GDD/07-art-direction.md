# Imaginophobia — Art Direction

**Version:** 2.0 (Release 1.0.0) | **Last Updated:** 2026-11-02

## Visual Style

- **สไตล์:** 2D pixel art มุมมองด้านข้าง (side-view)
- **โทนรวม:** มืด หม่น ชื้นแฉะ อึดอัด — ใช้ความมืดเป็นองค์ประกอบหลัก ไม่ใช่แค่ฉากหลัง
- **แนวทางศัตรู:** สีดำขาวสไตล์ contrast จัด ให้ความรู้สึกเกินจริง (surreal) — เอาคำอธิบายของแต่ละความกลัวมาเป็นสิ่งที่มองเห็นได้
- **Post-process:** ทั้งเฟรมผ่าน shader `Saturation` — `MainGame.ScreenManager.Saturation = 1` คือสีปกติ และถูกตั้งเป็น `0` (ขาวดำทั้งจอ) เมื่อผู้เล่นชน Autophobia จากนั้นไล่กลับ +0.3/วินาที

## Main Character Design

**สีหลัก : Navy Blue** (น้ำเงินเข้ม/น้ำเงินกรมท่า)

- บ่งบอกถึงลักษณะอาชีพ/เครื่องแบบช่างอย่างชัดเจน

**สีรอง : Brown & Beige** (น้ำตาล, น้ำตาลเทา และโทนสีเนื้อ)

- การใช้สีน้ำตาลตัดกับสีน้ำเงินให้เพิ่มความรู้สึกสมจริงและดูเป็นอุปกรณ์ช่างที่ใช้งานจริง

**สิ่งที่ปรับจากเวอร์ชันเดิม**

| สิ่งที่ปรับ                 | เหตุผล                                                                                                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ดวงตาที่เปิดกว้าง     | สื่อถึงความตื่นตระหนก ความไม่ไว้วางใจ                                                                                                           |
| ท่าทางที่ห่อตัว         | เป็น "ท่าป้องกัน" ทางวิทยาศาสตร์ สื่อว่าตัวละครพยายามทำให้ตัวเองดูเล็กลงและระมัดระวังมากขึ้น |
| การหันหน้ากลับไปมอง | ใช้ในมุมมองด้านหลังและมุมมอง 3/4 (เฉียง) เป็นหลักของความหวาดระแวง                                                          |
| สีที่หม่นและมืดลง     | สีน้ำเงินเข้มของชุดและหมวกถูกปรับให้หม่นและมืดลง และสีผิวซีดลง                                                         |

**ชุดอนิเมชันที่มีจริงในเกม** (`Character/spritesheet_player.json` — 960×360, 22 เฟรม 120×120)

| เฟรมใน atlas | ใช้ทำอะไร |
| --- | --- |
| `sprite_back` | ท่าหันหลัง (ตอนซ่อม / อ่านคลิปบอร์ด) |
| `sprite_idle_01..12` | ท่ายืน idle |
| `sprite_walk_01..09` | ท่าเดิน และท่าซุ่มเดิน (เล่นย้อนกลับเป็น `sneak-backward`) |

## Environments

### โถงอุโมง (Sewer)

คราบน้ำและตะไคร่ช่วยคุมโทนให้ฉากท่อดูชื้น แฉะ และอึดอัดขึ้น — 6960×1080 ยาวประมาณ 3.6 จอ

### ห้องไฟฟ้า (Electrical Room)

นำ inspiration จากห้องไฟที่พบได้ทั่วไปในชั้นใต้ดินของตึกต่างๆ แต่ปนความสกปรกและ texture ของท่อน้ำไปด้วย

ห้องไฟเป็นห้องที่มีแสงมากกว่าที่อื่น ๆ แสงสลัวเพื่อให้รู้สึกอบอุ่น ปลอดภัย เหมือนเป็น **safe zone** — ซึ่งเปลี่ยน concept ไปจากช่วง Game Jam ที่ห้องไฟสามารถมี entity ได้

**องค์ประกอบในห้อง** (จาก wireframe): hanging light bulb (broken) · light switch (deco) · entrance to sewer · useless door · locker for hiding · deco · **clipboard**

## Enemy / Phobia Design

แนวทาง: นำคำอธิบายของแต่ละความกลัวมาเป็นสิ่งที่มองเห็นได้ตามจินตนาการ แล้วนำ concept นั้นมาใช้เป็น mechanic ของ phobia

| Phobia                 | การออกแบบ                                                                                                                                                                                                                                                                                                                             | Mechanic ที่ผูกกัน                                                                                                                                                                                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Scopophobia**  | เหมือนหนอนที่มีลูกตาหลายดวงคอยจับตามอง แล้วพุ่งผ่านด้วยความเร็ว (`Phobias/sprite_scopophobia.png`)                                                                                                                                                                                                                  | ความเร็วที่พุ่งผ่าน = ความกดดันที่ได้รับเวลาถูกจับตามอง → ต้องหาที่ซ่อนเพื่อหลบความรู้สึกนั้น · ตอนมันมาไฟทั้งฉากเปลี่ยนเป็นสีแดง                                                                                                |
| **Autophobia**   | เงาร่างดำทึบ — ใช้ spritesheet ของผู้เล่นแล้วย้อมสีดำ (`_animatedSprite.Color = Color.Black`)                                                                                                                                                                                                                                                                                                                       | "You aren't scared of being alone, you are scared of NOT being alone" · เงาเดินตามความเร็วมากกว่าผู้เล่น |
| **Nyctophobia**  | "The unknown" — ความมืดที่ขยายตัวกลืนกินจอ (vignette `Softness = 15`)                                                                                                                                                                                                                                                                          | เมื่ออยู่ในความมืดนาน จอจะถูกกลืน (25 วินาทีจนมืดสนิท = สติ 0)                                                              |
| **Entamaphobia** | ผีที่ยืนอยู่หลังตู้เสื้อผ้าที่ปิดอยู่ — สูงมาก ผอมผิดปกติ หน้าเบี้ยว มือและขาใหญ่ยาว ให้ความรู้สึกว่า "ใหญ่จนไม่น่าจะใส่ในที่แคบได้ แต่ก็ใส่ได้" · ตัวใหญ่กว่าผู้เล่นหลายเท่า · atlas `Phobias/spritesheet_entamaphobia-texture.png` มี 6 เฟรม: `entama_stage_1..4` · `entama_hand` · `entama_jumpscare` | กลัวแสง (เข้าห้องที่มีแสงไม่ได้) · โผล่ทีละส่วนตาม stage ผ่านช่องใต้ประตู (ขา → มือกด → มือบีบ → หน้า) → ต้องแอบมองใต้ช่องประตู + ส่องไฟฉายเพื่อไล่กลับ · เปิดประตูตอนมัน active = `entama_jumpscare` เต็มจอ |

## UI / UX

**Main Menu** (`MainMenuScreen`, สร้างด้วย Gum)

- พื้นหลัง `UI/background_main.png` + **`EyeField`** — ฝูงดวงตาที่กระจายอยู่บนบริเวณมืดของภาพ มองตามเมาส์ กระพริบเป็นจังหวะและตอบสนองการคลิก (ใช้ชุดภาพ `UI/Eyes/sprite_sclera_A/B/C.PNG`, `sprite_pupil_A/B/C.PNG`, `sprite_eyelid_A/B/C.PNG`)
- ชื่อเกม "Imaginophobia" อยู่ด้านบน · ปุ่มเรียงลงมา: `Shift 1` (เริ่มเกม — ปุ่มใหญ่สุด) · `Index` (ปิดใช้งาน) · `Settings` · `Credits` · `Exit` · ลูกศร `<` `>` สองข้าง (ปิดใช้งาน)
- ตำแหน่ง/ขนาดทั้งหมดอ่านจาก `Layout` (design space 1920×1080)

**Settings** — dim panel + สไลเดอร์ `Ambience Volume` และ `SFX Volume` + ปุ่ม Back (`ESC` = กลับ)
**Pause overlay** (อยู่ใน `GameplayScreen`) — dim panel + สไลเดอร์ชุดเดียวกัน + ปุ่ม `Return to Menu` เปิดด้วย `ESC` หรือปุ่มมุมขวาบน
**Credits** — panel เลื่อนได้ (ScrollViewer) ที่ใช้ภาพ `slider_placeholder` เป็นราง และหัวจับหมุนตามการเลื่อน

**HUD** (มุมซ้ายบน, วาดด้วย `UIManager` + `TextManager`)

```
Sanity:                    [แถบสี 440×40]
Battery:                   [แถบขาว 250×20]
Valves repaired: n/5       (แสดงหลังเข้าฉาก sewer)
                                    00:00   ← MainTimer (mm:ss)
```

- สีของแถบ Sanity เปลี่ยนตามระดับ: `Normal` ขาว · `Anxious` `#a89e6c` · `Insane` `#752d22`
- ข้อความ tutorial อยู่กลางจอด้านบน (700, 100) และข้อความชั่วคราวสีเหลืองที่ (700, 200)
- ป้าย `sprite_spacebar` ลอยอยู่เหนือวัตถุที่โต้ตอบได้ และมีแถบเวลาซ้อนทับเมื่ออยู่ที่ตู้ (ซ่อน/cooldown)
