## สิ่งที่ต้องเตรียม

หูฟัง · เมาส์ · คีย์บอร์ด · โปรเจคเตอร์

## ขั้นตอนการทดสอบ

1. เปิดเกมให้คนที่มาทดสอบเล่น และถ่ายรูปผู้ทดสอบตอนเล่น
2. อธิบายระบบและวิธีการเล่นให้ผู้ทดสอบ (วิธีแก้ puzzles และวิธีรับมือ phobia ในเกม)
3. ผู้ทดสอบเล่นจริง
4. รับฟังรีวิวจากผู้ทดสอบและให้ทำแบบสอบถาม

## ชุดคำถามที่ใช้

### In-game Question

| คำถาม |
|---|
| รู้สึกกลัวขนาดไหนระหว่างเล่น? |
| มองแยกห้อง/ทางเดินออกยากไหม? |
| รู้สึกถึงสัญญาณเตือนก่อนเจอ phobia ไหม? |

### General Questions

| คำถาม |
|---|
| รู้สึกยังไงเมื่อเห็นเกมเป็นครั้งแรก |
| มีส่วนไหนในเกมที่ทำให้หงุดหงิดไหม |
| มีส่วนไหนในเกมที่ชอบเป็นพิเศษไหม |
| คิดว่าส่วนไหนเป็นตอนที่ตื่นเต้นที่สุดของการเล่น |

### Formal Elements

- Objective ชัดเจนไหม?
- เห็นความเปลี่ยนแปลงเมื่อค่า Sanity เปลี่ยนไหม?
- Strategy ในการเล่นคืออะไร?
- Minigame ยาก-ง่ายแค่ไหน?

### Procedure, Rules & Interface

- กติกาและ controls เข้าใจง่ายไหม?
- มีส่วนไหนของ control ที่รู้สึกแปลกไหม?
- อยากให้เพิ่ม UI อะไร?

### Dramatic Elements

- Monster design น่ากลัวไหม?
- ตัวละครแยกจากพื้นหลังชัดแค่ไหน?
- แสงและเสียงช่วยความน่ากลัวไหม?
- แยกเสียงซ้าย-ขวาชัดเจนไหม?

### Closing Question

- โดยรวมคิดว่ามีอะไรที่ควรปรับปรุงไหม
- จะจ่ายเงินซื้อเกมนี้ไหม
- ส่วนไหนของเกมที่ดึงดูดคุณให้เล่นมากที่สุด
- ส่วนไหนของเกมที่คิดว่าขาดหายไป
- ถ้าคิดว่าจะให้เกมนี้เป็นของขวัญ จะให้กับใคร

## ผลลัพธ์: Player Experience

**ความรู้สึกของผู้เล่น**

| รายการ | คะแนน |
|---|---|
| ความน่ากลัว | 2.5/5 |
| แยกห้อง/ทางเดินชัดเจน | 3.75/5 |
| สัญญาณเตือนก่อนเจอ phobia | 4.0/5 |
| ตัวละครแยกจากพื้นหลัง | 4.75/5 |

**แสงและเสียง** — ทุกคนตอบว่า แสง/เสียงช่วยทำให้เกมน่ากลัวขึ้น "อย่างมาก"

**ความคิดเห็นผู้เล่น**
- บรรยากาศเปลี่ยน น่ากลัวดี
- ไม่มี interface บอกวิธีการเล่น

## ผลลัพธ์: Player Actions

**Strategy ที่พบ**
- ตอบโต้ตามเสียงเตือน แล้วหนีเข้าที่ซ่อน
- ยอมโดนดาเมจเพื่อทำ Objective ให้เสร็จ
- บางคน "กดมั่ว" เพราะไม่เข้าใจระบบ

**ตัวเลขสำคัญ**
- ความยาก Minigame: 4/5 (ยากแต่ท้าทายดี)
- Pacing: กำลังไม่สั้นเกินไป มี 1 คนบอก minigame ยาวไป
- ความเข้าใจกติกา: ง่าย

**พฤติกรรมที่น่าสังเกต**
- ผู้เล่นที่ไม่ได้ใส่หูฟัง จะไม่สามารถรับรู้ถึง monster ได้

## Discussion

**Atmosphere**
- Monster ยังไม่น่ากลัว และเกมขึ้นอยู่กับการใช้เสียงมากเกินไปจนส่งผลกับ Gameplay (ผู้ทดสอบไม่สามารถคาดเดาการเคลื่อนไหวของ Monster ได้หากไม่ใส่หูฟัง)

**Mechanics**
- ค่า Sanity ไม่ส่งผลกับเกม บางคนไม่รู้ว่ามีค่า sanity อยู่
- ผู้ทดสอบชอบ Task ที่ท้าทาย แต่ว่ายากเกินไป

**Overall**
- Input การออกจาก Task ยังไม่ค่อยดี
- โดยรวมแสงและเสียงอยู่ในระดับที่ดี

## Key Findings

| ประเด็น | จำนวนคน | สิ่งที่ต้องทำ |
|---|---|---|
| มอนต้องน่ากลัวขึ้น | 3/6 | Redesign monster, เพิ่ม jumpscare, เพิ่มจำนวนมอน |
| Minigame | 2/6 | ทำง่ายขึ้น, มี guide วิธีเล่น, บันทึก progress ถ้าเดินออก |
| Objective ต้องชัดเจน | 2/6 | บอกเป้าหมาย/ทิศทางระหว่างเล่น |
| ประตู/ทางเดินแยกจากพื้นหลัง | 2/6 | ทำให้ต่างจาก locker ชัดเจน |
| Sanity/Battery UI | 2/6 | ทำให้เห็นชัด + sanity ต้องส่งผลต่อ gameplay จริง |
| ความเห็นเพิ่มเติม | 1/6 | Visual indicator ตอนมอนเกิด, ออกจาก task แล้วค้าง, เพิ่มเนื้อเรื่อง |

## Conclusion — งานที่ต้องทำ

**Redesign Monster ให้้น่ากลัวขึ้น**
- ปรับดีไซน์มอนให้้น่ากลัวกว่าเดิม
- เพิ่ม Jumpscare / ช่วงที่ทำให้ผู้เล่นตกใจ
- เพิ่มจำนวนและความหลากหลายของมอน
- เพิ่ม Guide / วิธีเล่นก่อนเริ่ม Minigame แต่ละแบบ
- ทำระบบบันทึก Progress — ถ้าเดินออกกลางคัน กลับมาแล้วไม่ต้องเริ่มใหม่
- ทำ Objective ให้ชัดเจนขึ้น เช่นอาจเพิ่ม hint หรือ marker ระหว่างเล่น

**ควรปรับปรุง**
- ทำประตู/ทางเดินแยกจากพื้นหลังโดยการปรับสี / Contrast ให้ประตูเด่นขึ้น และทำ Asset ประตูให้หน้าตาต่างจาก locker ชัดเจน
- ปรับ UI ค่า Sanity และ Battery ทำแถบให้เห็นชัดเจนขึ้น
- ทำให้ Sanity ส่งผลต่อ Gameplay จริง (ภาพบิดเบี้ยว/เอฟเฟกต์) ไม่ใช่แค่ตัวเลข

**เสริม**
- เพิ่ม Visual Indicator ตอน Monster เกิด — เพื่อคนที่ไม่ได้ใส่หูฟังเล่นได้
- เพิ่มเนื้อเรื่องให้ผู้เล่นเข้าใจบริบทของเกม
